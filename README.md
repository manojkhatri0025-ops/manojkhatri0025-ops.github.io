# Manoj Khatri's portfolio

Personal portfolio published with GitHub Pages at https://manojkhatri.name.np/.

## Edit the site

- `index.html`: content, project cards, and contact links.
- `assets/style.css`: layout, colors, and mobile styles.
- `assets/main.js`: theme and navigation behavior.
- `assets/manoj-khatri.webp`: optimized portrait.

Push changes to `main`; GitHub Pages publishes the root folder automatically. No build step, paid hosting, database, or API key is required. The repository is public.

The QR Scanner card currently uses an email inquiry link. Replace it with the owner's exact Google Play listing URL when available.

If the website address changes, update the canonical and social metadata in `index.html`, plus `sitemap.xml` and `robots.txt`.
